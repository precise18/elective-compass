Job Title: API Integration Developer
Company: IntegrAPI Africa

Job Description:
We are hiring an API Integration Developer to build and maintain integrations between third-party systems and our core platform. You will design robust API contracts, manage webhooks, and ensure reliable data exchange across partners and services.

Key Responsibilities:
- Design and implement RESTful API integrations with third-party platforms (payment gateways, CRMs, ERPs).
- Build webhook handlers and event-driven integrations with proper retry and idempotency logic.
- Manage API authentication and authorisation patterns (OAuth 2.0, API keys, JWT).
- Implement JSON and XML data transformation and mapping between systems.
- Monitor API health, error rates, and latency using API management tools.
- Maintain integration documentation and OpenAPI specifications.

Requirements:
- Strong understanding of RESTful API design principles.
- Proficiency in Python or Java for building integration services.
- Knowledge of JSON and XML serialisation and transformation.
- Familiarity with message queue concepts for asynchronous integration patterns.

Nice-to-Have:
- Experience with API gateways (Kong, AWS API Gateway, Apigee).
- Knowledge of GraphQL as an alternative API style.
- Familiarity with JMS and enterprise messaging for system integration.
- Experience with distributed systems fault tolerance and partial failure handling.
