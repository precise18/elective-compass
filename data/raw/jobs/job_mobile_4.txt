Job Title: React Native Developer (Junior)
Company: MobileSphere Studio

Job Description:
We are seeking a Junior React Native Developer to build high-quality cross-platform mobile applications. You will work with React Native and modern JavaScript frameworks.

Key Responsibilities:
- Build and maintain iOS and Android apps using React Native.
- Design and develop reusable components and screens.
- Manage application state using Redux or Context API.
- Integrate with third-party APIs and native modules.
- Fix bugs and optimize app performance.
- Collaborate with designers to implement UI mockups.

Requirements:
- Knowledge of JavaScript (ES6) and React framework.
- Understanding of mobile development concepts.
- Familiarity with Git and command line.
- Willingness to learn new technologies.

Nice-to-Have:
- Experience with React Native CLI or Expo.
- Knowledge of Firebase for mobile apps.
- Understanding of CI/CD for mobile (App Center, Fastlane).
